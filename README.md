## Original description

It will automatically wash the vegetables with some liquids.


Components:

1. Arduino
2. Relay module
3. conveyor belt
4. IR Sensors
5. 12 V DC power supply
6. submersible motor
7. bread board
8. liquid container

software tools:

1. Arduino IDE
