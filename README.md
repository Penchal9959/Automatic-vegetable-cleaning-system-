# Automatic Vegetable Cleaning System

A reviewed and corrected version of this project, with a build check and
fuller documentation, is in [embedded-iot-projects / vegetable-cleaning](https://github.com/Penchal9959/embedded-iot-projects/tree/main/vegetable-cleaning) alongside the others from the same
series.

## What this was

A conveyor that washes vegetables as they pass under a nozzle. An IR sensor
detects produce arriving and runs the pump only while something is underneath
it, so water is not sprayed at an empty belt.

## Hardware

Arduino UNO, relay module, IR sensors, submersible pump, 12 V supply, a
cardboard-and-tape conveyor.
