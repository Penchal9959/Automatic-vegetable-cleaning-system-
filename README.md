# Automatic Vegetable Cleaning System

> **Archived.** The reviewed and corrected version of this project lives in
> [embedded-iot-projects / vegetable-cleaning](https://github.com/Penchal9959/embedded-iot-projects/tree/main/vegetable-cleaning), alongside the others from the same series. Work happens there;
> nothing here changes.

## What this was

A conveyor that washes vegetables as they pass under a nozzle. An IR sensor
detects produce arriving and runs the pump only while something is underneath
it, so water is not sprayed at an empty belt.

## Hardware

Arduino UNO, relay module, IR sensors, submersible pump, 12 V supply, a
cardboard-and-tape conveyor.

## Why it was archived

Twelve one-off repositories of two files each is not a portfolio, it is a
list. They were consolidated into one maintained repository with the
documentation and the build check they never had. This one is kept so
existing links still resolve.
